# What this computer can do

Action: `app.status`

## What it is for

Tells which actions are ready here, which need a step first (and the step), and which cannot run on this computer. The assistant uses it so its answers say what is missing.

## Steps in the app

This has no screen of its own: the assistant and other apps use it.

## Fields

- `domain`: Optional: only one area, for example speech.

## Limits

- Nothing.
