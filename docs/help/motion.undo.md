# Undo the last change

Action: `motion.undo`

## What it is for

Bring a video project back as it was before the last change. Use it again to go further back.

## Steps in the app

1. Choose **Undo the last change** on the Motion graphics screen, or ask the assistant.

## Fields

- `composition_id`: The project.

## Limits

- Twenty earlier versions are kept for each project; older ones are dropped.
- A video already made stays in the Library.

## Needs

- Nothing else: the change is only written down. Motion graphics must be set up to make the video.

## Examples

- "Undo that."

## Problems

- A scene or project that does not fit is refused, and the message says what to change. Nothing changes until it is right.
