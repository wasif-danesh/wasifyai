What changes from today's screens

  • The model button in Code gets a fourth tab, Your agent, next to Recommended, On this computer and Cloud. It lists Claude Code and Codex. Each one shows whether it is signed in and which plan it is on, then the models that plan offers, with "Its own choice" first. The other three tabs are Wasify AI's own agent, as today.
  • Setting up and signing in happen in that tab. "Set up" installs both programs (694 MB, said before it starts). "Sign in" opens the program's own sign-in page in your browser. Wasify AI never sees the password or the token.
  • Once, before the first session on Claude Code or Codex, a short note says how it differs: it does not ask during a turn, it stays in the folder, and every turn can be undone.
  • Two modes, not three. "Ask me" is shown greyed, with one line saying why. Sessions already set to "Ask me" start in Plan.
  • The bar shows the program and "Your Claude plan" or "Your ChatGPT plan" where it shows dollars today. Opening it shows what the program reported (cost and tokens). It says there is no limit of ours, because the plan's own limits apply.
  • When the plan says no (signed out, limit reached), the program's own words are shown in a card, with one way forward.
  • Extensions says, in one line on the screen and in the session's "+" menu, that they are for Wasify AI's own agent; Claude Code and Codex use their own.
  • Projects shows which agent each session ran on. Settings › Code gets a short "Your agent programs" list with the same sign-in state and "Sign in" and "Remove".
  • Not in this mockup: Gemini CLI (waiting on question 3); "Add your own agent"; Scheduled on a harness (stage H3).
