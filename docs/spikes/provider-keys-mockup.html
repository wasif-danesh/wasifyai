Mockup (not built), 2026-11-11, third version. Settings › Your keys only holds keys, by product. Where a product runs is chosen in its model picker: a new Cloud tab lists every model that the product's saved keys can run, beside Recommended, On this computer and More.

What changes from today's screens

  • Settings › Your keys keeps one row per product and holds only keys. A product can have keys for several providers (fal.ai, WaveSpeed, Runware; the text providers for Chat), each with Test and Remove. Nothing about models or "where it runs" is set there.
  • The model picker of each product gains a Cloud tab. It lists every model of that product from each provider with a saved key, grouped by provider, with its price. Choosing one makes the product run there, as choosing a local model does now.
  • No key yet: the Cloud tab says which providers offer models for this product and links to Your keys.
  • Recommended can include a cloud model once its key is saved; On this computer and More stay as they are.
  • What is sent: a cloud model's status line names its provider. One line on the screen says that what you give goes to that provider.
